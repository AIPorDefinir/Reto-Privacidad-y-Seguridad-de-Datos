\section{Registros de acceso y autorizaciones}

Para saber quién y cuándo tuvo acceso a los datos, usaremos AWS CloudTrail. Este servicio registra cada vez que alguien descarga o sube un archivo al bucket, junto con el usuario, el archivo, la fecha y la hora. Al final del proyecto exportaremos estos registros y los compararemos con el proceso descrito en la sección anterior.
